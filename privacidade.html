Política de privacidade

O Zeus Lembretes é uma aplicação de uso pessoal, usada apenas pelo dono da conta Google que a autorizou.

  • Dados acessados: título e data das tarefas abertas do Google Tasks (escopo tasks.readonly), somente leitura.
  • Uso: exibir essas tarefas num painel privado do próprio dono. Nada é alterado no Google Tasks.
  • Compartilhamento: nenhum. Os dados não são vendidos, cedidos nem enviados a terceiros.
  • Guarda: o token de acesso fica apenas no computador do dono; o acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso de informações recebidas das APIs do Google segue a Google API Services User Data Policy, incluindo os requisitos de uso limitado.
